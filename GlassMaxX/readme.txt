GlassMaxX
=========

Author: basj

This animated cursor set contains 16 cursors.

Files included:
  - Arrow.ani
  - Help.ani
  - IBeam.cur
  - Handwriting.cur
  - NO.cur
  - AppStarting.ani
  - Cross.ani
  - SizeNS.ani
  - SizeWE.ani
  - SizeNWSE.ani
  - UpArrow.ani
  - SizeNESW.ani
  - Button.ani
  - SizeAll.ani
  - Hand.ani
  - Wait.ani

Installation:
  1. Right-click install.inf
  2. Select 'Install'
  3. Open Control Panel > Mouse > Pointers
  4. Select 'GlassMaxX' from the Scheme dropdown

Downloaded from Cursors-4U.com
https://www.cursors-4u.com
