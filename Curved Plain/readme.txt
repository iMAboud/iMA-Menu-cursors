Curved Plain Light
==================

Author: ArdentAA

This animated cursor set contains 15 cursors.

Files included:
  - alternate.cur
  - help.cur
  - unavailable.cur
  - diagonal resize.cur
  - diagonal resize2.cur
  - hand.cur
  - horizontal resize.cur
  - pen.cur
  - move.cur
  - precision.cur
  - vertical resize.cur
  - text.cur
  - normal.cur
  - busy .ani
  - busy.ani

Installation:
  1. Right-click install.inf
  2. Select 'Install'
  3. Open Control Panel > Mouse > Pointers
  4. Select 'Curved Plain Light' from the Scheme dropdown

Downloaded from Cursors-4U.com
https://www.cursors-4u.com
