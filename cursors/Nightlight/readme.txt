Nightlight
==========

Author: Xiandi

This animated cursor set contains 14 cursors.

Files included:
  - Arrow.cur
  - Help.cur
  - Wait.ani
  - Cross.cur
  - IBeam.cur
  - No.cur
  - SizeNS.cur
  - SizeWE.cur
  - SizeNWSE.cur
  - SizeNESW.cur
  - SizeAll.cur
  - UpArrow.cur
  - Hand.cur
  - AppStarting.ani

Installation:
  1. Right-click install.inf
  2. Select 'Install'
  3. Open Control Panel > Mouse > Pointers
  4. Select 'Nightlight' from the Scheme dropdown

Downloaded from Cursors-4U.com
https://www.cursors-4u.com
