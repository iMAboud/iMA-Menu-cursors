BlueGlass
=========

Author: AeroPurple

This animated cursor set contains 15 cursors.

Files included:
  - Arrow.cur
  - Help.cur
  - Cross.cur
  - IBeam.cur
  - No.cur
  - Handwriting.cur
  - SizeNS.cur
  - SizeWE.cur
  - SizeNWSE.cur
  - SizeNESW.cur
  - UpArrow.cur
  - SizeAll.cur
  - Hand.cur
  - Wait.ani
    - Wait (32-48-64).ani (multisize: 32, 48, 64px)
    - Wait (72-96-128).ani (multisize: 72, 96, 128px)
  - AppStarting.ani
    - AppStarting (32-48-64).ani (multisize: 32, 48, 64px)

Installation:
  1. Right-click install.inf
  2. Select 'Install'
  3. Open Control Panel > Mouse > Pointers
  4. Select 'BlueGlass' from the Scheme dropdown

Downloaded from Cursors-4U.com
