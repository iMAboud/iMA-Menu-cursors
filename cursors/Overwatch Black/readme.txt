Overwatch Black
===============

Author: IDarques

Notes:
Support Me @ MyBoosty

https://boosty.to/i.darques

This animated cursor set contains 17 cursors.

Files included:
  - horz.cur
  - dgn2.cur
  - vert.cur
  - dgn1.cur
  - handwriting.cur
  - move.cur
  - cross.cur
  - text.cur
  - link.cur
  - pin.cur
  - alternate.cur
  - person.cur
  - pointer.cur
  - help.cur
  - unavailiable.cur
  - work.ani
    - work_32-48-64.ani (multisize: 32, 48, 64px)
  - busy.ani
    - busy_32-48-64.ani (multisize: 32, 48, 64px)

Installation:
  1. Right-click install.inf
  2. Select 'Install'
  3. Open Control Panel > Mouse > Pointers
  4. Select 'Overwatch Black' from the Scheme dropdown

Downloaded from Cursors-4U.com
https://www.cursors-4u.com
