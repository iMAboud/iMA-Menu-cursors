BlowFly
=======

Author: Vampothika

Notes:
Ive always wanted to do a blowfly cursor, since I love the colour of them so much, and I finally finished it! cool animations for busy and working in background. A very accurate and fun cursor to use....just hold off on the flyspray please..hehe.

This animated cursor set contains 15 cursors.

Files included:
  - IBeam.cur
  - Cross.cur
  - Help.cur
  - Arrow.cur
  - No.cur
  - SizeNS.cur
  - UpArrow.cur
  - SizeWE.cur
  - SizeNWSE.cur
  - SizeNESW.cur
  - SizeAll.cur
  - Handwriting.cur
  - Hand.cur
  - AppStarting.ani
  - Wait.ani

Installation:
  1. Right-click install.inf
  2. Select 'Install'
  3. Open Control Panel > Mouse > Pointers
  4. Select 'BlowFly' from the Scheme dropdown

Downloaded from Cursors-4U.com
https://www.cursors-4u.com
