Breathe 2.0
===========

Author: pelaird

Notes:
Take another breath and enjoy this updated cursor!

New cursors for resize, move, and precision.

Highly visible on both light and dark backgrounds, yet covers very few pixels on your screen, never hiding anything underneath it.

This animated cursor set contains 14 cursors.

Files included:
  - Arrow.cur
  - Help.ani
    - Help_60.ani (60px)
  - AppStarting.ani
    - AppStarting_60.ani (60px)
  - Cross.cur
  - IBeam.cur
  - Handwriting.cur
  - No.cur
  - SizeNS.cur
  - SizeWE.cur
  - SizeNWSE.cur
  - SizeNESW.cur
  - SizeAll.cur
  - Hand.cur
  - Wait.ani
    - Wait_60.ani (60px)

Installation:
  1. Right-click install.inf
  2. Select 'Install'
  3. Open Control Panel > Mouse > Pointers
  4. Select 'Breathe 2.0' from the Scheme dropdown
