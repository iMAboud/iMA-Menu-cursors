Glistening Magnetism
====================

Author:
  - Gemmee
    https://www.wincustomize.com/users/2899751/Gemmee

Notes:
Glistening Magnetism this cursor gains attention from the eyes that gives thumbs a break. A rested thumb gives nice thumbs up. A very busy cursor set with billions of stars with colors. Enjoy...

This animated cursor set contains 13 cursors.

Installed by install.inf (9 files):
  - Help_32-48-64.ani (multisize: 32, 48, 64px)
  - Arrow_32-48-64.ani (multisize: 32, 48, 64px)
  - AppStarting_32-48-64.ani (multisize: 32, 48, 64px)
  - SizeNS_32-48-64.ani (multisize: 32, 48, 64px)
  - Wait_32-48-64.ani (multisize: 32, 48, 64px)
  - SizeNWSE_32-48-64.ani (multisize: 32, 48, 64px)
  - SizeWE_32-48-64.ani (multisize: 32, 48, 64px)
  - SizeNESW_32-48-64.ani (multisize: 32, 48, 64px)
  - SizeAll_32-48-64.ani (multisize: 32, 48, 64px)

Extras (8 files) — not installed automatically:
These are alternates and spare cursors included with the set. To use one,
copy it over the installed file it replaces, then re-apply the scheme in
Control Panel > Mouse > Pointers.
  - Help_96.ani (96px)
  - Arrow_96.ani (96px)
  - AppStarting_96.ani (96px)
  - Cross_48.ani (48px)
  - IBeam_48.ani (48px)
  - Handwriting_48.ani (48px)
  - No_48.ani (48px)
  - Wait_96.ani (96px)

Installation:
  1. Right-click install.inf
  2. Select 'Install'
  3. Open Control Panel > Mouse > Pointers
  4. Select 'Glistening Magnetism' from the Scheme dropdown
