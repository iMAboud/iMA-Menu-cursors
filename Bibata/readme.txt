Bibata Set
==========

Author: Abdulkaiz Khatri

This animated cursor set contains 21 cursors.

Installation:
  1. Right-click install.inf
  2. Select 'Install'
  3. Open Control Panel > Mouse > Pointers
  4. Select 'Bibata Set' from the Scheme dropdown

Files included:
  - Alternate.cur
  - Busy.ani
    - Busy_32.ani (32px)
    - Busy_48.ani (48px)
    - Busy_64.ani (64px)
  - Cross.cur
  - Dgn1.cur
  - Dgn2.cur
  - Grabbing.cur
  - Handwriting.cur
  - Help.cur
  - Horz.cur
  - Link.cur
  - Move.cur
  - Pan.cur
  - Person.cur
  - Pin.cur
  - Pointer.cur
  - Text.cur
  - Unavailable.cur
  - Vert.cur
  - Work.ani
    - Work_32.ani (32px)
    - Work_48.ani (48px)
    - Work_64.ani (64px)
  - Zoom-in.cur
  - Zoom-out.cur
