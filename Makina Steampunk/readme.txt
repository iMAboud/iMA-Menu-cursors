Makina Steampunk Set
====================

Author: Apocalypse_67

Notes:
A bit of SteamPunk for dark themes.

This animated cursor set contains 20 cursors.

Files included:
  - Help.cur
  - Cross.cur
  - Arrow.cur
  - IBeam.cur
  - Handwriting.cur
  - SizeNS.cur
  - SizeS.cur
  - SizeWE.cur
  - SizeE.cur
  - SizeNWSE.cur
  - No.cur
  - SizeSE.cur
  - SizeNESW.cur
  - SizeSW.cur
  - SizeAll.cur
  - UpArrow.cur
  - Hand.cur
  - Button.cur
  - Wait.ani
  - AppStarting.ani

Installation:
  1. Right-click install.inf
  2. Select 'Install'
  3. Open Control Panel > Mouse > Pointers
  4. Select 'Makina Steampunk Set' from the Scheme dropdown

Downloaded from Cursors-4U.com
