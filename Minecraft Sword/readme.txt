Minecraft Netherite Sword Set v.4
=================================

Author: Hakku_

Notes:
This cursor has an animated design, created for Minecraft fans.
In cursorFx version 2.16 the animations work perfectly.
Inside the download file there are 6 cursors, the same cursor but with few changes.
I recommend adjusting the cursor to the size you want.

Este cursor tiene un diseño animado, creado para los fans de Minecraft.
En cursorFx version 2.16 las animaciones funcionan perfectamente.
Dentro del archivo de descarga hay 6 cursores, son el mismo cursor pero con pocos cambios.

This animated cursor set contains 16 cursors.

Files included:
  - Help.cur
  - No.ani
  - Wait.ani
  - Arrow.ani
    - Arrow_32.ani (32px)
    - Arrow_48.ani (48px)
  - SizeNS.ani
  - AppStarting.ani
  - SizeS.ani
  - SizeWE.ani
  - SizeNWSE.ani
  - SizeSE.ani
  - UpArrow.cur
  - SizeE.ani
  - Button.cur
  - SizeNESW.ani
  - SizeSW.ani
  - Hand.ani
    - Hand_32.ani (32px)
    - Hand_48.ani (48px)

Installation:
  1. Right-click install.inf
  2. Select 'Install'
  3. Open Control Panel > Mouse > Pointers
  4. Select 'Minecraft Netherite Sword Set v.4' from the Scheme dropdown
