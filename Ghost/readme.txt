Ghost
=====

Author: treetog

This animated cursor set contains 16 cursors.

Files included:
  - Arrow.cur
  - Help.ani
  - Wait.ani
  - Cross.ani
  - IBeam.ani
  - Handwriting.cur
  - NO.ani
  - AppStarting.ani
  - SizeNS.ani
  - SizeWE.ani
  - SizeNWSE.ani
  - SizeAll.cur
  - UpArrow.cur
  - SizeNESW.ani
  - Hand.ani
  - Button.ani

Installation:
  1. Right-click install.inf
  2. Select 'Install'
  3. Open Control Panel > Mouse > Pointers
  4. Select 'Ghost' from the Scheme dropdown

Downloaded from Cursors-4U.com
https://www.cursors-4u.com
